# Discontinued product planning

This folder contains historical planning drafts from the BetterOption POC/MVP.
Development is discontinued. There is no active commercial rollout, pricing
offer, product-launch schedule, or commitment to implement the proposed work.

The material is retained as context for the original experiments:

- Business hypotheses, provider-cost assumptions, and pricing worksheets.
- Product-name/domain research, with the former deployment domain anonymized.
- Hosting choices, alpha/public roadmaps, and proposed release sequencing.
- Draft compliance records and launch checklists from the earlier product phase.

Future-tense statements and readiness decisions belong to the original draft;
they do not establish a current service or completed review. Technical deployment
experiments are separated into [engineering history](../engineering-history/README.md).

For implemented behavior, use the [technical documentation](../../README.md)
and source code.
