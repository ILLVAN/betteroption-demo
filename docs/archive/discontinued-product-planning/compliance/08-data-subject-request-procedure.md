# Data-subject request procedure

Status: operational draft; staging dry run required

## Intake and identity

1. Receive requests at **[privacy contact email]**. Record case ID, receipt time,
   request type, scope, and deadline; do not copy unnecessary profile content.
2. Acknowledge promptly. Calculate the GDPR one-month response deadline and any
   lawful extension; record reasons and notify the requester within the original
   month if extended.
3. Verify identity proportionately. Prefer an authenticated account action or
   reply from the verified address. Request additional identification only when
   reasonably necessary and delete it after verification.
4. If the request concerns another person or an agent, verify authority.

## Search map

Search by account UUID and verified email in:

- accounts, personas, legal acceptances, sessions, invitations/recovery;
- workspaces, messages, raw sections, facts, review events, CV records and
  editable application drafts;
- saved jobs/references, matches, route estimates, feedback/application states;
- provider telemetry, auth/security events, support and incident systems;
- current backups (note expiry rather than restoring every backup unless needed);
- approved providers where BetterOption cannot fulfil the action directly.

Do not expose another user's data or confidential security information.

## Actions

- **Access:** provide purposes, categories, recipients/transfers, retention,
  source, rights, AI/profiling information, and a copy in intelligible form.
- **Correction:** update inaccurate user data and propagate where required.
- **Deletion:** remove the account aggregate, active sessions,
  profile/CV/match/draft data and provider-held data where applicable; record only minimal completion
  evidence. Explain the 14-day backup ageing period.
- **Restriction:** suspend matching/provider calls and mark data restricted while
  the request is assessed.
- **Portability:** provide user-provided/observed data in structured JSON where
  Art. 20 applies; distinguish inferred data.
- **Objection:** stop the challenged Art. 6(1)(f) purpose unless compelling
  grounds or legal claims justify it; document the balancing decision.
- **Consent withdrawal:** stop future optional CV processing. Explain any
  completed one-off request and delete remaining data where applicable.

## Close

Second-person review the response, send securely, record actions/recipients and
completion date, and delete working copies. If refusing or charging for a
manifestly unfounded/excessive request, obtain legal approval and explain the
complaint/judicial-remedy rights.
