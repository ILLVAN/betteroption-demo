# Superseded private-alpha roadmap

The earlier plan treated `v0.8.0` as the first online private alpha. On
4 August 2026 the project plan changed: a small invitation-only friend alpha is
now the near-term hosted milestone, while `v0.8.0` is the directional public
release after roughly two to three months of testing and cost validation.

Use the canonical
[`roadmap-to-public-release.md`](roadmap-to-public-release.md) for current
milestones, gates and exposure boundaries. Versioned release notes and Git
history retain the earlier plan for traceability.
