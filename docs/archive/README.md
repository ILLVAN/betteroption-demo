# Documentation archive

BetterOption development is discontinued. These records preserve the technical
iteration and the product exploration around the POC/MVP.

| Collection | Scope |
| --- | --- |
| [Engineering history](engineering-history/README.md) | Versioned designs, release notes, local guides, provider reviews, and deployment experiments |
| [Discontinued product planning](discontinued-product-planning/README.md) | Former business/pricing assumptions, naming research, release roadmaps, and compliance drafts |

Archived instructions describe their original checkpoint. Future-tense launch
or implementation statements are historical; they are not an active roadmap.
Deployment addresses and workstation paths have been replaced with examples.
Runtime database backups are excluded from the cleaned source snapshot.

Start with the [technical documentation](../README.md) for the portfolio overview.
